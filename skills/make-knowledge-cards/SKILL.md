# 知识卡片生成器

把一篇文章或笔记提炼成 5~8 张用于学习和复习的知识卡片。输入是用户粘贴的文本或本地 .md/.txt 文件，输出是 Markdown 卡片。

## 工作流程

1. 获取原文
   - 用户粘贴了文本 → 直接使用
   - 用户给出 .md/.txt 文件路径 → 读取文件
   - 用户给出 URL、PDF 或其他格式 → 不要尝试处理，告知本技能只接受粘贴文本和本地 .md/.txt 文件，请用户把内容复制粘贴过来
2. 通读全文，列出候选知识点：概念定义、原理机制、方法步骤、重要数据结论、作者核心论点
3. 筛选：只保留对理解文章主题真正重要的知识点，去掉次要细节、过渡句、客套话和无信息量内容
4. 去重：同一知识点在文中多处出现的，合并成一张卡片
5. 决定数量：
   - 候选知识点 ≥ 5 个 → 按重要性排序，取前 5~8 个
   - 候选知识点 < 5 个 → 只生成实际数量的卡片，并在末尾说明原文信息量只支撑得起这几张
   - 候选超过 8 个时：优先丢弃最次要的；若干个密切相关的小要点（如一组同类技巧）可合并为一张主题卡片，标题如实反映它是一组要点（如"三个实用技巧：……"）
   - 绝不为了凑数量而拆细或注水。凑数卡片会稀释复习效率，违背本技能的目的
6. 按"卡片格式"逐张写卡片
7. 输出前按"质量红线"逐条自检

## 卡片格式

每张卡片严格使用此结构：

```markdown
## 卡片 N：{标题}

**核心知识**：{一句话陈述这个知识点，尽量具体}

**解释**：{2~4 句话，用自己的话讲清楚，内容必须忠于原文}

**例子** 或 **自测**（二选一）：{原文给出例子时，用 **例子** 摘录原文的例子；原文没有例子时，用 **自测** 出一个问题并附一句话答案，答案必须能在原文中找到}
```

标题要具体、脱离文章也能看懂。反例："什么是缓存"；正例："HTTP 强缓存通过 Cache-Control 控制有效期"。

## 质量红线

- 一张卡片只讲一个知识点。解释里出现"以及""另外"时，检查是否混入了第二个知识点，拆开或删掉次要的
- 不编造。卡片中的任何事实、数字、例子都必须来自原文；解释可以换一种说法，但不能加入原文没有的信息。原文带有"据说""研究表明"等限定词时照抄限定，不把传闻或单一研究升级成确定事实
- 不重复。两张卡片讲同一件事时合并成一张
- 不注水。原文撑不起 5 张卡片就直接少出，并说明原因

## 输出结构

1. 开头一句话：从什么文章提炼出了几张卡片
2. 依次列出全部卡片
3. 仅当卡片不足 5 张时，在末尾说明原因（如：原文为短讯，仅包含 3 个独立知识点）

## 示例

输入（用户粘贴）：

```text
复利是指利息并入本金后继续产生利息，也就是"利滚利"。假设本金 1 万元，年利率 5%，
按复利计算，10 年后约为 1.63 万元，而单利只有 1.5 万元。复利的威力主要来自时间：
年限越长，差距越大。爱因斯坦曾说复利是"世界第八大奇迹"。
```

输出：

```markdown
从这段关于复利的文字中提炼出 3 张知识卡片。

## 卡片 1：复利是利息并入本金继续生息

**核心知识**：复利把每期利息并入本金，下一期按新本金计息，即"利滚利"。

**解释**：单利只对原始本金计息，复利则对"本金 + 已产生利息"的总额计息。这使得同样利率下，复利的终值增长速度随时间加快。

**例子**：本金 1 万元、年利率 5% 时，复利 10 年约得 1.63 万元，单利只有 1.5 万元。

## 卡片 2：复利与单利的差距随时间拉大

**核心知识**：年限越长，复利与单利的差距越大。

**解释**：复利每期都在更大的基数上计息，时间越长基数优势积累越多，因此长期持有的差距远大于短期。

**自测**：同样本金和利率下，10 年期复利与单利的差距和 3 年期相比哪个大？（答：10 年期，差距随时间扩大）

## 卡片 3：爱因斯坦称复利为"世界第八大奇迹"

**核心知识**：爱因斯坦把复利称为"世界第八大奇迹"。

**解释**：这一说法被广泛引用，用来说明复利效应的威力。

**自测**：这句话形容的是哪种金融现象？（答：复利）

---

说明：原文为一段 4 句话的短文，仅包含 3 个独立知识点，故生成 3 张卡片。
```

## 边界（不做的事）

- 不抓取网页：用户给 URL 时请其复制正文粘贴
- 不处理 PDF：请用户转成文本或 .md/.txt
- 不导出 Anki：输出是 Markdown，用户可自行导入其他工具
- 无图形界面：卡片以 Markdown 文本呈现
